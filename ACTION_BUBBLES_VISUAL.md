## Button Interactions

### Primary Button (Blue)
- **Hover Effect**: Slightly darker blue + scale up
- **Click**: Opens Irembo service page in new tab
- **Visual**: Blue background, white text, shadow effect

### Secondary Button (Gray)
- **Hover Effect**: Slightly darker gray + scale up
- **Click**: Either sends a follow-up question OR opens external link
- **Visual**: Gray/white background, dark text, border

## Color Scheme

### Light Mode
- **Primary Button**: Blue (#2563eb) with white text
- **Secondary Button**: White with gray border and dark text
- **Hover**: Darker shades + scale transform

### Dark Mode
- **Primary Button**: Blue (#2563eb) with white text + glow
- **Secondary Button**: Dark gray (#2a2a2a) with lighter text
- **Hover**: Lighter shades + scale transform

## Animation Effects

1. **Appear**: Fade in from bottom (0.3s)
2. **Hover**: Scale up 1.05x + color change (0.2s)
3. **Click**: Scale down 0.95x then bounce back (0.1s)
4. **External Link Icon**: Subtle rotation on hover

## Accessibility

✅ **Keyboard Navigation**: Tab through actions, Enter to activate
✅ **Screen Readers**: Descriptive labels with action type
✅ **Touch Targets**: Minimum 44x44px for mobile
✅ **Color Contrast**: WCAG AA compliant
✅ **Focus Indicators**: Clear outline on keyboard focus

## Real-World User Flow

```
Citizen Journey: Registering Land

1. Opens chat → "What is the price for land registration?"
   ↓
2. Reads AI response: "5,000 RWF, 7-14 days"
   ↓
3. Sees action bubbles
   ↓
4. Clicks "View Requirements" (secondary action)
   ↓
5. Reads requirements list
   ↓
6. Clicks "Register Land Now" (primary action)
   ↓
7. Redirected to Irembo portal
   ↓
8. Completes registration ✅

Time saved: ~5 minutes (no searching for service)
Clicks reduced: From 10+ to 2
```
